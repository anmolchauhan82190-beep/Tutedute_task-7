
# Task 7 - CSS Responsive Issues: Media Queries & Variables

## Project Overview
This project focuses on making the Laundry Services website responsive across desktop, tablet, and mobile devices using CSS Media Queries and CSS Variables.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- CSS Variables

## Features Implemented

### 1. Responsive Navbar
- Desktop: Displays logo, navigation links, and username.
- Tablet: Reduces the font sizes and element dimensions.
- Mobile: Hides navigation links and displays only the logo and username.

### 2. Responsive Hero Section
- Desktop: Displays text on the left and laundry image on the right.
- Tablet: Adjusts text sizes, image sizes, and alignment.
- Mobile: Changes the layout to a vertical column with text, button, and image.

### 3. CSS Variables
CSS custom properties are used to maintain reusable styling values, including:
- Primary and secondary colors
- Text colors
- Button background color
- Font family

### 4. Flexbox Layout
Flexbox is used to arrange navbar elements and hero content.

## Responsive Breakpoints
- Desktop: Above 900px
- Tablet: 601px to 900px
- Mobile: 600px and below

## How to Run the Project
1. Download or extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Resize the browser or use Chrome DevTools to test responsiveness.

## Conclusion
The Laundry Services website has been made responsive using CSS Flexbox, Media Queries, and CSS Variables without using Bootstrap.
